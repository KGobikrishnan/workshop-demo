4. HOW DATABASE (PSQL) & BACKEND (PYTHON) CONNECT
--------------------------------------------------------------------------------
Step 1: config.py
   PostgreSQL connection string create panrom:
   SQLALCHEMY_DATABASE_URI = "postgresql://postgres@localhost:5432/vvk"

Step 2: models.py
   Database tables define panrom (e.g., Complaint, SportsProduct, etc.)
   class Complaint(db.Model):
       id = db.Column(db.Integer, primary_key=True)
       student_name = db.Column(db.String(120), nullable=False)
       status = db.Column(db.String(20), default='Open')

Step 3: app.py
   db.init_app(app)
   db.create_all() -> Tables illana PostgreSQL-la automatic-ah create aagidum!

5. HOW FRONTEND (HTML/JS) & BACKEND (PYTHON) COMMUNICATE
--------------------------------------------------------------------------------
Frontend & Backend connect panna 2 methods use pannirukom:

Method A: Server-Side Template Rendering (Jinja2)
   1. User '/complaints' open panranga.
   2. Python Backend (app.py) PostgreSQL-la irunthu data edukuthu:
      data = Complaint.query.all()
   3. Antha data-va HTML template-ku anupum:
      return render_template('complaint.html', complaints=data)
   4. HTML-la Jinja loop use panni display aagum:
      {% for c in complaints %} <tr><td>{{ c.title }}</td></tr> {% endfor %}

Method B: Asynchronous REST API (Fetch / JSON)
   1. User button click panranga (e.g., "Add to Cart" or "Update Status").
   2. JavaScript (main.js) backend API-ku background-la JSON request send pannum.
   3. Backend process panni JSON response return pannum:
      return jsonify({"success": True, "message": "Updated!"})
   4. Page reload aagama instant-ah update aagum!

6. DETAILED EXPLANATION OF ALL 14 MODULES
--------------------------------------------------------------------------------

1. COMPLAINT MANAGEMENT SYSTEM:
   - What it does: Campus grievances lodging & resolution tracking.
   - Flow: Student name, reg no, category (Hostel, Lab, Transport) submit panranga.
     Admins status-ah (Open -> In-Progress -> Resolved) update pannalam.

2. CLOUD FILE MANAGEMENT SYSTEM:
   - What it does: College study materials & notes cloud storage.
   - Flow: Files (PDF, DOCX, ZIP) upload aagi server-la secure UUID name-la save aagum.
     File size, file type, uploader name track panni direct download & delete pannalam.

3. STUDENT PERFORMANCE PREDICTION USING AI:
   - What it does: Forecasts final semester GPA & Letter Grades.
   - Flow: Attendance %, Internal marks, and Study hours calculate panni composite 
     score generate pannum. Google Gemini AI personalized counseling text deliver pannum.

4. BUS TRACKING SYSTEM:
   - What it does: Campus bus fleet tracking & GPS telemetry.
   - Flow: Bus route, current stop, next stop, live ETA (mins), speed (km/h), and 
     driver contact details display pannum with simulated GPS advancement.

5. HEADLINE IN INDIA:
   - What it does: Pan-India news bulletin with instant publishing.
   - Flow: Tech, Education, Sports, National news filter pannalam. New flash headlines
     submit pannalam with trending badges.

6. E-COMMERCE FOR SPORTS PRODUCTS:
   - What it does: College sports gear store with live inventory.
   - Flow: Products showcase, "Add to Cart" calculation, "Add Product" inventory popup modal, 
     and simulated UPI checkout order booking.

7. AI CODE REVIEWER AND BUG FIXER:
   - What it does: Multi-language static analyzer & security scanner.
   - Flow: Code snippet (Python, JS, C++, SQL) paste panna, Google Gemini AI runtime bugs,
     SQLi/XSS security leaks, Time Complexity O(N), and refactored code output tharum.

8. STUDENT ASSESSMENT USING AI:
   - What it does: Automated adaptive technical examination.
   - Flow: Interactive quiz submit pannathum, AI candidate accuracy calculate panni 
     subject strengths, weakness areas, and study recommendations provide pannum.

9. CUSTOMER RELATIONSHIP MANAGEMENT (CRM):
   - What it does: Corporate placement & MoU recruiter pipeline.
   - Flow: Company name, deal value, interaction notes track panni pipeline stages 
     (Lead -> Contacted -> Proposal -> Won) manage panrom.

10. FAKE NEWS DETECTION & REPORTING SYSTEM:
    - What it does: NLP misinformation classifier.
    - Flow: Article title, URL, and body analyze panni sensationalism markers scan pannum.
      AI Credibility Score (0-100%) and truth verdict provide pannum.

11. GOLD AND SILVER FAKE / PURITY DETECTION:
    - What it does: Metallurgical Archimedes hydrostatic purity test.
    - Flow: Density = Weight_in_Air / (Weight_in_Air - Weight_in_Water).
      Calculated density-ah BIS Hallmark standards (24K, 22K 916, 18K 750, Sterling Silver) 
      oda compare panni genuine vs counterfeit test calculate pannum.

12. CRICKET CLUB MANAGEMENT SYSTEM:
    - What it does: Vivekanandha Warriors cricket squad & tournament tracker.
    - Flow: Player batting average, strike rate, wickets taken, live match scorecards, 
      and upcoming fixtures view/register pannalam.

13. TWO WHEELER SERVICE AND MAINTENANCE:
    - What it does: Automotive campus workshop job-card manager.
    - Flow: Bike model, vehicle registration, reported issues, and cost estimate save panni
      mechanic assignment and service lifecycle (Received -> In-Progress -> Ready) track panrom.

14. INTERCOLLEGIATE REGISTRATION MANAGEMENT:
    - What it does: Technical symposium & hackathon delegate pass system.
    - Flow: Multi-college participants register panni automated unique Badge Ticket IDs 
      (e.g., VVK-TECH-9012) generate aagum with team members attendance roster.
